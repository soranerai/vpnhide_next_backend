## English

Kernel module and vpnhide-ctl now support per-app hook mask overrides (kernel + Java/LSPosed) that take priority over the global mask for that app's uid.

## Русский

Модуль ядра и vpnhide-ctl теперь поддерживают переопределение маски хуков (ядро + Java/LSPosed) для отдельного приложения — с приоритетом над глобальной маской для uid этого приложения.
